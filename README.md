# 🔢 로또

## 🔷 기능 요구사항 정리

| **구분**     | **기능명**         | **세부 설명**                                                                                                       |
|------------|-----------------|-----------------------------------------------------------------------------------------------------------------|
| **입력**     | 로또 구입 금액 입력     | 사용자에게 `"구입금액을 입력해 주세요."` 메시지와 함께 로또 구입 금액을 입력받는다.                                                               |
|            | 당첨 번호 입력        | 사용자에게 `"당첨 번호를 입력해 주세요."` 메시지와 함께 당첨 번호를 입력받는다.                                                                 |
|            | 보너스 번호 입력       | 사용자에게 `"보너스 번호를 입력해 주세요."` 메시지와 함께 보너스 번호를 입력받는다.                                                               |
| **입력 전처리** | 구입 금액 전처리       | 입력받은 구입 금액 문자열의 앞뒤 공백을 제거하고, 숫자로 변환한다. 이때 숫자로 변환이 불가능 하다면 예외 처리(`”구입 금액은 숫자여야 합니다."`)한다.                        |
|            | 당첨 번호 파싱        | 입력받은 당첨 번호를 쉼표(`,`)로 분리한다.                                                                                      |
|            | 당첨 번호 전처리       | 각 당첨 번호의 앞뒤 공백을 제거한다.                                                                                           |
|            | 보너스 번호 전처리      | 입력받은 보너스 번호의 앞뒤 공백을 제거한다.                                                                                       |
| **입력 검증**  | 구입 금액 양수 검증     | 구입 금액이 양수인지 검증하고, 그렇지 않으면 예외 처리(`”구입 금액은 양수여야 합니다.”`)한다.                                                        |
|            | 구입 금액 단위 검증     | 파싱한 구입 금액이 1,000원 단위로 나누어떨어지는지 검증하고, 그렇지 않으면 예외 처리(`"구입 금액은 1000원 단위여야 합니다."`)한다.                               |
|            | 당첨 번호 개수 검증     | 파싱한 당첨 번호가 6개인지 검증하고, 그렇지 않으면 예외 처리한다.                                                                          |
|            | 당첨 번호 숫자 변환 검증  | 파싱한 각 당첨 번호를 정수로 변환하고, 변환할 수 없으면 예외 처리한다.                                                                       |
|            | 당첨 번호 범위 검증     | 각 당첨 번호가 1~45 범위의 숫자인지 검증하고, 그렇지 않으면 예외 처리한다.                                                                   |
|            | 당첨 번호 중복 검증     | 당첨 번호 6개에 중복이 없는지 검증하고, 중복이 있으면 예외 처리한다.                                                                        |
|            | 보너스 번호 숫자 변환 검증 | 파싱한 보너스 번호를 정수로 변환하고, 변환할 수 없으면 예외 처리한다.                                                                        |
|            | 보너스 번호 범위 검증    | 보너스 번호가 1~45 범위의 숫자인지 검증하고, 그렇지 않으면 예외 처리한다.                                                                    |
|            | 보너스 번호 중복 검증    | 보너스 번호가 당첨 번호 6개와 중복되지 않는지 검증하고, 중복이 있으면 예외 처리한다.                                                               |
| **로또**     | 로또 수량 계산        | 구입 금액을 1,000원으로 나누어 구매할 로또 수량을 계산한다.                                                                            |
|            | 로또 발행           | 계산된 수량만큼 로또를 발행한다. 각 로또는 1~45 범위에서 중복 없는 6개의 숫자로 구성된다.                                                          |
|            | 로또 번호 정렬        | 발행된 각 로또의 번호를 오름차순으로 정렬한다.                                                                                      |
| **당첨 확인**  | 일치 번호 개수 계산     | 각 로또와 당첨 번호를 비교하여 일치하는 번호의 개수를 계산한다.                                                                            |
|            | 보너스 번호 일치 확인    | 일치 번호가 5개인 경우, 보너스 번호 일치 여부를 확인한다.                                                                              |
|            | 당첨 순위 판정        | 일치 개수와 보너스 일치 여부에 따라 당첨 순위를 결정한다. (6개 = 1등, 5개+보너스 = 2등, 5개 = 3등, 4개 = 4등, 3개 = 5등)                             |
|            | 당첨 통계 집계        | 모든 로또의 당첨 결과를 순위별로 집계한다.                                                                                        |
| **수익률 계산** | 총 상금 계산         | 각 순위별 당첨 개수와 상금을 곱하여 총 상금을 계산한다.                                                                                |
|            | 수익률 계산          | 총 상금을 구입 금액으로 나누고 100을 곱하여 수익률을 계산한다.                                                                           |
|            | 수익률 반올림         | 수익률을 소수점 둘째 자리에서 반올림한다.                                                                                         |
| **출력**     | 로또 수량 출력        | 구매한 로또 수량을 `"{수량}개를 구매했습니다."` 형식으로 출력한다.                                                                        |
|            | 로또 번호 출력        | 발행된 모든 로또의 번호를 한 줄에 하나씩 `[번호1, 번호2, ..., 번호6]` 형식으로 출력한다. 로또 번호는 오름차순으로 정렬되어 있다.                                |
|            | 당첨 통계 헤더 출력     | `"당첨 통계"` 메시지와 구분선 `"---"`을 출력한다.                                                                               |
|            | 당첨 내역 출력        | 5등부터 1등까지 순서대로 `"{일치 개수}개 일치 ({상금}원) - {개수}개"` 형식으로 출력한다. 2등의 경우 `"5개 일치, 보너스 볼 일치 ({상금}원) - {개수}개"` 형식으로 출력한다. |
|            | 수익률 출력          | `"총 수익률은 {수익률}%입니다."` 형식으로 출력한다.                                                                                |
| **예외 처리**  | 예외 메시지 출력       | 잘못된 입력 발생 시 `"[ERROR]"`로 시작하는 에러 메시지를 출력한다.                                                                     |
|            | 재입력 처리          | 예외 발생 시 해당 입력 단계부터 다시 입력을 받는다.                                                                                  |

> 위 표는 기능 구현 목록을 담습니다. 프리코스 진행 방식에서 제시된 "기능 요구사항에 기재되지 않은 내용은 스스로 판단하여 구현한다"에 해당하는 내용은 아래 이렇게 판단했습니다에 기재했습니다.

## 🤔 이렇게 판단했습니다

- **입력값의 앞뒤 공백은 제거하여 처리합니다**
    - 구입 금액, 당첨 번호, 보너스 번호 모두 입력 시 앞뒤 공백을 제거합니다.
    - 당첨 번호의 경우 쉼표로 분리한 각 번호의 앞뒤 공백도 제거합니다.
    - 사용자 편의성을 높이고, `"1,2,3,4,5,6"`과 `"1, 2, 3, 4, 5, 6"` 를 동일하게 처리하기 위함입니다.
- **보너스 번호는 당첨 번호와 중복될 수 없습니다**
    - 실제 로또 게임에서 보너스 번호는 당첨 번호 6개를 뽑은 후 남은 숫자 중에서 추첨됩니다.
    - 따라서 보너스 번호가 당첨 번호 6개 중 하나와 동일하면 잘못된 입력으로 처리합니다.
- **당첨 금액 기준**
    - 1등: 2,000,000,000원
    - 2등: 30,000,000원
    - 3등: 1,500,000원
    - 4등: 50,000원
    - 5등: 5,000원
    - 2개 이하 일치는 당첨 내역에 포함하지 않습니다.
- **수익률 계산 방식**
    - `(총 상금 / 구입 금액) × 100`으로 계산합니다.
    - 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시합니다.
